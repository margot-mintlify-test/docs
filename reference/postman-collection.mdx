# Overview

We've created a [Postman](https://www.postman.com/) collection to make it easy for you to make experimental calls to our API. This collection provides a library of ready-made API calls that you can edit and/or directly hit "Send" on, for your own Opal setup.


## Using Postman

To use the Postman Collection, follow these steps:

1. In your own Postman workspace, select **Import**. Go to the **Link** tab, paste the above JSON link, and finish the import.

![](/images/reference/175169f-Screen_Shot_2022-07-14_at_2.08.28_PM.png "Screen Shot 2022-07-14 at 2.08.28 PM.png")

2. Enter your Opal API token by clicking **Opal API** in the left sidebar, then navigating to **Authorization** > **Token**. To generate an API token, check out our instructions under [Authentication](/reference/authentication).

![](/images/reference/1e5f2db-Screen_Shot_2022-07-14_at_1.28.19_AM.png "Screen Shot 2022-07-14 at 1.28.19 AM.png")

3. (optional) If you need to customize the Opal server base URL, navigate to **Variables** > **baseUrl** > **Current Value**. Enter your alternative base URL here. You'll need to do this if your organization is running an on-prem version of Opal with its own custom URL, or if you want to hit a sandbox version of the Opal server.

![](/images/reference/b01e02e-Screen_Shot_2022-07-14_at_1.32.05_AM.png "Screen Shot 2022-07-14 at 1.32.05 AM.png")

4. Click any of the API endpoints in the left sidebar to get started testing!

![](/images/reference/a2e6ade-Screen_Shot_2022-07-14_at_1.34.35_AM.png "Screen Shot 2022-07-14 at 1.34.35 AM.png")
