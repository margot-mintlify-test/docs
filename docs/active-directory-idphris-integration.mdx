If your organization uses Active Directory as an Identity Provider, you can additionally designate it as an [IDP/HRIS Integration](/v3.2/docs/add-your-first-idphr-provider). Doing so allows Opal to sync your Active Directory identities and their attributes, on top of syncing and managing access to entitlements.

## Getting started

<Info>
  If you use self-hosted Opal, you must be on [version 1.1017.0](/changelog) or later to use Active Directory as an IDP.
</Info>

Before you set up Active Directory as your IDP, you must first create an [Active Directory integration](/docs/active-directory) in Opal.

Next, set up Active Directory as your IDP by following instructions here:

* [Add Your First IDP/HR Provider](/v3.2/docs/add-your-first-idphr-provider)
* [Add Additional IDP/HR Providers](/v3.2/docs/add-additional-idphr-providers)
