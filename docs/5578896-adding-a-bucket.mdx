Opal lets your developers find and request access to GCP Cloud Storage buckets. Follow these steps to add GCP buckets to your Opal dashboard.

## 1. Go to Cloud Storage

Access the [Cloud Storage browser using this link](https://console.cloud.google.com/storage/browser) or find it by navigating to Cloud Storage in the search bar.

## 2. Label your bucket

Opal only adds permissions for buckets that you label with Opal. To do this, add a label to your bucket in the Cloud Storage dashboard.

![](/images/docs/51f3948-Bucket_1.png "Bucket_1.png")

## Access a bucket in Opal

If you successfully labeled your bucket in GCP, the new bucket resource appears in Opal in the **Inventory** under **Resources**.
